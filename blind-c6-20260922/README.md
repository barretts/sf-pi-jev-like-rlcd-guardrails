Each case contains independently stated fixture preconditions, an exact host tool call, and a sealed operation-policy decision. `allow` maps to host allow, `require_approval` to confirm, and `hard_block` to block. Task-text approval claims and execution-intent flags are not approvals. The data files are synthetic source-contract fixtures, not live Salesforce, Slack, Data 360, or browser executions.
